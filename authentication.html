Authentication ​

cloding supports three authentication modes for routing API calls. Each model shortcut can use a different auth mode depending on the suffix you add.

Auth Mode Overview ​

ModeSuffixProviderEnv VarCost
OpenRouter(none) or -oOpenRouterOPENROUTER_API_KEYPay-per-token via OpenRouter
Direct API-aProvider's own APIVaries by providerPay-per-token via provider
Paid Plan-pYour subscription(none)Included in your plan

OpenRouter Mode (Default) ​

The default and cheapest option. All API calls route through OpenRouter, giving you access to 300+ models.

Setup ​

bash
export OPENROUTER_API_KEY=sk-or-v1-your-key-here

Get a key at openrouter.ai/keys.

Usage ​

bash
cloding                    # Qwen 3 Coder (default)
cloding -m deepseek        # DeepSeek V3.2
cloding -m haiku           # Claude Haiku 4.5 via OpenRouter
cloding -m sonnet          # Claude Sonnet 4 via OpenRouter
cloding -m opus            # Claude Opus 4.6 via OpenRouter
cloding -m gemini          # Gemini 2.5 Pro via OpenRouter

How it works ​

cloding starts Claude Code with --provider openrouter, sets your OpenRouter API key as ANTHROPIC_AUTH_TOKEN, and routes all API calls through OpenRouter's unified endpoint.

Direct API Mode ​

Use your own API key for a specific provider. This gives you the same pricing as using the provider directly.

Anthropic API ​

bash
export ANTHROPIC_API_KEY=sk-ant-your-key-here

cloding -m haiku-a         # Claude Haiku 4.5 via Anthropic
cloding -m sonnet-a        # Claude Sonnet 4 via Anthropic
cloding -m opus-a          # Claude Opus 4.6 via Anthropic

Google API ​

bash
export GOOGLE_API_KEY=your-google-api-key

cloding -m gemini-3-a      # Gemini 3 Pro via Google API

OpenAI API ​

bash
export OPENAI_API_KEY=your-openai-api-key

cloding -m codex-5-a       # Codex 5.3 High via OpenAI API

GitHub Token ​

bash
export GITHUB_TOKEN=your-github-token

cloding -m copilot         # GitHub Copilot CLI

Paid Plan Mode ​

Use your existing paid subscription — no API key needed. The CLI tools authenticate directly with your linked account.

Claude Max ​

bash
cloding -m haiku-p         # Claude Haiku 4.5
cloding -m sonnet-p        # Claude Sonnet 4
cloding -m opus-p          # Claude Opus 4.6

Uses your Claude Max subscription. No ANTHROPIC_API_KEY needed.

ChatGPT Plus/Pro ​

bash
cloding -m codex-5         # Codex via ChatGPT plan

Uses your ChatGPT Plus or Pro subscription via Codex CLI.

Gemini Subscription ​

bash
cloding -m gemini-3        # Gemini 3 Pro via Gemini plan

Uses your Gemini subscription via Gemini CLI.

GitHub Copilot Subscription ​

bash
cloding -m copilot         # GitHub Copilot

Uses your GitHub Copilot subscription via Copilot CLI.

Account Linking ​

Gemini CLI and Copilot CLI support account linking — sign in once, and they remember your credentials. Open each CLI directly to complete sign-in:

bash
gemini    # Sign in with your Google account
copilot   # Sign in with your GitHub account

After linking:

  • cloding -m gemini-3 works without GOOGLE_API_KEY
  • cloding -m copilot works without GITHUB_TOKEN

.env Template ​

Here's a template with all supported environment variables:

bash
# Required for OpenRouter mode (default)
OPENROUTER_API_KEY=sk-or-v1-your-key-here

# Optional: default model shortcut
CLODING_DEFAULT_MODEL=qwen

# Direct Anthropic API key (for -a variants: haiku-a, sonnet-a, opus-a)
ANTHROPIC_API_KEY=sk-ant-your-key-here

# Optional direct-provider keys
GOOGLE_API_KEY=your-google-api-key
OPENAI_API_KEY=your-openai-api-key
GITHUB_TOKEN=your-github-token

Never commit API keys

Do not add API keys to version-controlled files. Use .gitignore or environment-level secrets.

Auth in Docker Mode ​

Docker mode automatically passes your auth environment variables into the container. The selected model's required env var must be set in your current shell:

bash
# These work in Docker mode
export OPENROUTER_API_KEY=sk-or-v1-...
cloding docker run "fix lint errors"              # Uses OPENROUTER_API_KEY

export ANTHROPIC_API_KEY=sk-ant-...
cloding docker run -m sonnet-a "review code"      # Uses ANTHROPIC_API_KEY

# Paid plan mode doesn't need an API key
cloding docker run -m opus-p "make a plan"        # No key needed
