Configuration ​

cloding is configured through environment variables and CLI flags. All underlying CLI tool flags are also supported — cloding passes everything through.

Environment Variables ​

VariableRequiredDefaultDescription
OPENROUTER_API_KEYFor OpenRouter mode—Your OpenRouter API key
CLODING_DEFAULT_MODELNoqwenDefault model shortcut or OpenRouter model ID
ANTHROPIC_API_KEYFor -a variants—Direct Anthropic API key
GOOGLE_API_KEYFor gemini-3-a—Direct Google API key
OPENAI_API_KEYFor codex-5-a—Direct OpenAI API key
GITHUB_TOKENFor copilot—GitHub personal access token

Internal variables

These are set internally by cloding when spawning Claude Code. Do not set them manually:

  • ANTHROPIC_BASE_URL — Set to OpenRouter endpoint
  • ANTHROPIC_AUTH_TOKEN — Set to your OpenRouter key
  • ANTHROPIC_API_KEY — Set to empty string (prevents Anthropic-only routing)
  • ANTHROPIC_MODEL — Set to resolved OpenRouter model ID

Setting API Keys ​

bash
# Required for OpenRouter mode (default)
export OPENROUTER_API_KEY=sk-or-v1-your-key-here

# Optional: direct API keys for -a variants
export ANTHROPIC_API_KEY=sk-ant-your-key-here
export GOOGLE_API_KEY=your-google-api-key
export OPENAI_API_KEY=your-openai-api-key
export GITHUB_TOKEN=your-github-token

To persist across sessions, add them to your shell profile:

bash
# ~/.bashrc
export OPENROUTER_API_KEY=sk-or-v1-your-key-here
export ANTHROPIC_API_KEY=sk-ant-your-key-here     # optional
export GOOGLE_API_KEY=your-google-api-key          # optional
export OPENAI_API_KEY=your-openai-api-key          # optional
bash
# ~/.zshrc
export OPENROUTER_API_KEY=sk-or-v1-your-key-here
export ANTHROPIC_API_KEY=sk-ant-your-key-here     # optional
powershell
# $PROFILE
$env:OPENROUTER_API_KEY = "sk-or-v1-your-key-here"
$env:ANTHROPIC_API_KEY = "sk-ant-your-key-here"   # optional
bash
# ~/.config/fish/config.fish
set -gx OPENROUTER_API_KEY sk-or-v1-your-key-here
set -gx ANTHROPIC_API_KEY sk-ant-your-key-here     # optional

Never commit API keys

Do not add your API key to version-controlled files like .env in a public repo. Use .gitignore or environment-level secrets (e.g., GitHub Actions secrets, Vercel env vars).

Changing the Default Model ​

By default, cloding uses Qwen 3 Coder. To change this:

bash
export CLODING_DEFAULT_MODEL=haiku

Or specify per-session with -m:

bash
cloding -m sonnet

The -m flag always takes precedence over the environment variable.

Configuration Precedence ​

When multiple sources set the same option, cloding uses this priority (highest first):

  1. CLI flags — -m sonnet always wins
  2. Environment variables — CLODING_DEFAULT_MODEL=haiku
  3. Built-in defaults — qwen

For example:

bash
# Environment says haiku, but CLI says sonnet -> uses sonnet
CLODING_DEFAULT_MODEL=haiku cloding -m sonnet

CLI Flag Passthrough ​

All underlying CLI tool flags work as-is. cloding passes everything through transparently:

bash
# Claude Code flags
cloding --allowedTools Read,Write,Bash
cloding --verbose

# Gemini CLI flags
cloding -m gemini-3 --sandbox

# Codex CLI flags
cloding -m codex-5 --full-auto

Unknown flags are passed through to the underlying CLI tool.

TIP

Any flag you'd pass to the underlying CLI tool works with cloding. Think of cloding as an intelligent router that picks the right tool, sets up auth, and passes your flags through.

Per-Project Configuration ​

You can set project-specific defaults using a .env file in your project root:

bash
# .env (add to .gitignore!)
OPENROUTER_API_KEY=sk-or-v1-your-key-here
CLODING_DEFAULT_MODEL=deepseek

direnv

If you use direnv, you can create a .envrc file that automatically loads your API key when you cd into a project:

bash
# .envrc
export OPENROUTER_API_KEY=sk-or-v1-your-key-here
export CLODING_DEFAULT_MODEL=sonnet

Run direnv allow to activate it.

Shell Completion ​

cloding inherits Claude Code's shell completion. If you've set up Claude Code completions, they work with cloding too.

Verifying Your Configuration ​

Check that everything is working:

bash
# Verify API key works
cloding --list-models

# Verify default model
echo $CLODING_DEFAULT_MODEL

# Run a quick test
cloding -p "say hello"

If --list-models shows the model table with pricing, you're all set.
