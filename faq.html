FAQ ​

General ​

What is cloding? ​

cloding is a universal wrapper that lets you run 5 coding CLI tools — Claude Code, Gemini CLI, Codex CLI, GitHub Copilot CLI, and OpenCode — with any model. Route through OpenRouter for cheap multi-model access, use your own API keys, or link your paid subscription.

Is cloding a fork of Claude Code? ​

No. cloding doesn't modify, patch, or fork any CLI tool. It starts the chosen tool with the right configuration and handles model selection. Zero modified binaries.

Which CLI tools does cloding support? ​

ToolInstall
Claude Codenpm install -g @anthropic-ai/claude-code
Gemini CLInpm install -g @google/gemini-cli
Codex CLInpm install -g @openai/codex
GitHub Copilot CLInpm install -g @github/copilot
OpenCodenpm install -g opencode-ai

Do I need all 5 tools installed? ​

No. You only need Claude Code (the default) to get started. Install other tools as you want to use them.

Do I need an API key? ​

It depends on the mode:

  • OpenRouter mode (default) — Yes, you need an OPENROUTER_API_KEY
  • Direct API mode (-a suffix) — Yes, you need the provider's API key
  • Paid plan mode (-p suffix) — No, uses your existing subscription

Is cloding free? ​

cloding itself is free and open source. You pay for model usage through your chosen auth mode — OpenRouter tokens, direct API usage, or your paid subscription.

Models ​

Which model should I use? ​

For most tasks, Qwen 3 Coder (the default) is the best value — it's 42x cheaper than Claude Opus and handles day-to-day coding well. For complex architecture or planning, switch to Sonnet or Opus. If you have a paid plan (Claude Max, ChatGPT, Gemini), use that for zero per-token cost. See Models & Pricing for a full comparison.

What are the 3 auth modes? ​

SuffixModeExample

See Authentication for details.

Can I use Claude models through cloding? ​

Yes. All Claude models are available through OpenRouter, direct API, or your Claude Max subscription:

bash
cloding -m sonnet        # via OpenRouter
cloding -m sonnet-a      # via Anthropic API
cloding -m sonnet-p      # via Claude Max subscription

Can I use non-Claude tools? ​

Yes. cloding supports Gemini CLI, Codex CLI, Copilot CLI, and OpenCode:

bash
cloding -m gemini-3      # Gemini CLI with your Gemini plan
cloding -m codex-5       # Codex CLI with your ChatGPT plan
cloding -m copilot       # Copilot CLI

Do all models work equally well? ​

No. Claude Code relies on tool use (function calling) to edit files and run commands. Some models handle this better than others. Qwen, DeepSeek, Claude, Gemini, and Codex all work well. Smaller or older models may struggle. See Custom Models — Tool Use.

Can I use models not listed in the shortcuts? ​

Yes. Pass any OpenRouter model ID directly:

bash
cloding -m meta-llama/llama-4-scout

Browse all available models at openrouter.ai/models.

Cost ​

How much does a typical session cost? ​

With the default model (Qwen 3 Coder), a 30-minute coding session costs approximately $0.07. With a paid plan (-p suffix), it costs $0 per token. See the cost comparison table.

Is there a free tier? ​

OpenRouter sometimes offers free credits for new accounts. Check openrouter.ai for current promotions. Some models on OpenRouter also have free tiers. Paid plan models (-p suffix) cost $0 per token if you have a subscription.

How do I monitor my spending? ​

Check your usage on the OpenRouter dashboard. You can also set spending limits on your API key.

Security ​

Is my code sent to third parties? ​

Yes. Your code is sent to the API provider for the model you're using:

  • OpenRouter models — Sent to OpenRouter, which routes to the model provider
  • Direct API models (-a) — Sent directly to the provider (Anthropic, Google, OpenAI)
  • Paid plan models (-p) — Sent through the CLI tool's native channel

Review each provider's privacy policy for details.

Is Docker mode fully secure? ​

Docker mode is a practical safety layer, not a security guarantee. It prevents the most common risks (agent reading secrets, destructive commands on host), but containers still have network access and can modify files in the mounted workspace. See Docker — Security Model.

Can cloding access my API keys and secrets? ​

In normal mode, the agent has the same access as your terminal — including .env files, SSH keys, and anything else in your home directory. Use Docker mode to isolate the agent from sensitive files.

Compatibility ​

Does cloding work on Windows? ​

Yes. cloding works anywhere the underlying CLI tools and Node.js work — macOS, Linux, and Windows (including WSL).

Does cloding work with VS Code? ​

cloding is a terminal tool, not an IDE extension. Run it in VS Code's integrated terminal alongside your editor.

Can I use cloding in CI/CD? ​

Yes. Use the -p flag for non-interactive mode:

bash
cloding -p "run the test suite and fix any failing tests"

Set OPENROUTER_API_KEY as a CI secret.

Does cloding work with all CLI tool features? ​

Yes. cloding passes through all flags and features to the underlying CLI tool. Anything the tool supports, cloding supports.

Can I use cloding with MCP servers? ​

Yes. Claude Code's MCP (Model Context Protocol) configuration works with cloding. Set up your MCP servers as you normally would with Claude Code.

Does cloding work with account linking? ​

Yes. Gemini CLI and Copilot CLI support account linking. Sign in to each CLI once, and cloding will use your linked account:

bash
gemini    # Sign in once
copilot   # Sign in once

# Then use with cloding
cloding -m gemini-3     # Uses linked Gemini account
cloding -m copilot      # Uses linked Copilot account
