Quick Install ​

$npm install -g cloding
bash
# OpenRouter (cheapest, default)
export OPENROUTER_API_KEY=sk-or-v1-your-key-here
cloding                          # Qwen 3 Coder at $0.12/Mtok

# Or use your paid plan — no API key needed
cloding -m opus-p                # Claude Max subscription
cloding -m codex-5               # ChatGPT Plus/Pro
cloding -m gemini-3              # Gemini subscription
cloding -m copilot               # GitHub Copilot

How It Works ​

cloding is a universal wrapper for coding CLI tools — no forks, no patches, no modified binaries.

1. Install — npm install -g cloding adds the cloding CLI globally along with your preferred tool CLIs.

2. Pick a tool + model — Choose from 5 CLI tools and 20+ model shortcuts. Each model can route through OpenRouter, direct API, or your paid plan.

3. Code — You get the exact same CLI experience — file editing, terminal access, tool use — with whatever model you choose.
