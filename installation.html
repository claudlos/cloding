Installation ​

Get cloding running in under a minute.

Prerequisites ​

  • Node.js 18+ — Download
  • Node.js 24+ — Required only if you want to use GitHub Copilot CLI

Install cloding ​

bash
npm install -g cloding
Permission denied?

If you get EACCES errors on Linux/macOS:

bash
# Option 1: Use sudo
sudo npm install -g cloding

# Option 2: Fix npm permissions (recommended)
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
export PATH=~/.npm-global/bin:$PATH
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
npm install -g cloding

Install Tool CLIs ​

Install at least one CLI tool that cloding will wrap. Claude Code is the default:

bash
# Required — Claude Code (default tool)
npm install -g @anthropic-ai/claude-code

# Optional — install any tools you want to use
npm install -g @google/gemini-cli     # For gemini models
npm install -g @openai/codex          # For codex models
npm install -g @github/copilot        # For copilot (requires Node 24+)
npm install -g opencode-ai            # For opencode

TIP

You only need Claude Code to get started. Install other tools as you need them.

Set Up Authentication ​

cloding supports 3 auth modes. Set up the one(s) you want to use:

Option 1: OpenRouter (cheapest, default) ​

Get an API key at openrouter.ai/keys, then:

bash
export OPENROUTER_API_KEY=sk-or-v1-your-key-here

This gives you access to Qwen, DeepSeek, Claude, Gemini, and 300+ other models through OpenRouter.

Option 2: Direct API Keys ​

Use your own API keys for specific providers:

bash
# Anthropic API (for haiku-a, sonnet-a, opus-a)
export ANTHROPIC_API_KEY=sk-ant-your-key-here

# Google API (for gemini-3-a)
export GOOGLE_API_KEY=your-google-api-key

# OpenAI API (for codex-5-a)
export OPENAI_API_KEY=your-openai-api-key

# GitHub (for copilot)
export GITHUB_TOKEN=your-github-token

Option 3: Paid Plan (no API key needed) ​

If you have a paid subscription, just use the -p suffix:

bash
cloding -m opus-p       # Uses your Claude Max subscription
cloding -m codex-5      # Uses your ChatGPT Plus/Pro plan
cloding -m gemini-3     # Uses your Gemini subscription
cloding -m copilot      # Uses your GitHub Copilot subscription

Account Linking (Gemini / Copilot) ​

For Gemini CLI and Copilot CLI, you can link your account directly. Open each CLI once and complete sign-in:

bash
gemini    # Sign in with your Google account
copilot   # Sign in with your GitHub account

After linking, these work without API keys:

bash
cloding -m gemini-3     # Uses linked Gemini account
cloding -m copilot      # Uses linked Copilot account

Make Keys Permanent ​

Add your API keys to your shell profile so they persist across sessions:

bash
# ~/.bashrc
export OPENROUTER_API_KEY=sk-or-v1-your-key-here
export ANTHROPIC_API_KEY=sk-ant-your-key-here    # optional
export GOOGLE_API_KEY=your-google-api-key          # optional
export OPENAI_API_KEY=your-openai-api-key          # optional
bash
# ~/.zshrc
export OPENROUTER_API_KEY=sk-or-v1-your-key-here
export ANTHROPIC_API_KEY=sk-ant-your-key-here    # optional
export GOOGLE_API_KEY=your-google-api-key          # optional
export OPENAI_API_KEY=your-openai-api-key          # optional
powershell
# $PROFILE
$env:OPENROUTER_API_KEY = "sk-or-v1-your-key-here"
$env:ANTHROPIC_API_KEY = "sk-ant-your-key-here"    # optional
bash
# ~/.config/fish/config.fish
set -gx OPENROUTER_API_KEY sk-or-v1-your-key-here
set -gx ANTHROPIC_API_KEY sk-ant-your-key-here     # optional

Never commit API keys

Do not add your API keys to version-controlled files like .env in a public repo. Use .gitignore or environment-level secrets.

Verify Installation ​

bash
cloding --list-models

This should display all available models with their pricing. If it works, you're ready to go.

Optional: Docker ​

If you want to use Docker mode for sandboxed execution:

  • Docker Desktop — Mac · Windows · Linux
  • Or Docker Engine — Install guide

Optional: Pipeline Mode ​

For pipeline mode, you also need Python 3.11+:

bash
cd pipeline && pip install -e .

Updating ​

bash
npm update -g cloding

Uninstalling ​

bash
npm uninstall -g cloding

Troubleshooting Installation ​

cloding: command not found ​

Your global npm bin directory may not be in your PATH:

bash
npm config get prefix
# Add the resulting path + /bin to your PATH

Claude Code version mismatch ​

cloding requires a recent version of Claude Code that supports the --provider flag:

bash
npm update -g @anthropic-ai/claude-code

API key not working ​

Verify your OpenRouter key is valid:

bash
curl https://openrouter.ai/api/v1/models \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" | head -20

If you get an authentication error, check that your key starts with sk-or-v1- and hasn't expired.

For more issues, see Troubleshooting.
