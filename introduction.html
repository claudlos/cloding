Introduction ​

Not a fork

cloding doesn't modify, patch, or fork any CLI tool. It's a thin configuration wrapper — zero modified binaries. Just smart routing.

cloding is a universal wrapper that lets you run 5 coding CLI tools with any model — via OpenRouter, direct API keys, or your paid subscription plan.

3 Auth Modes ​

Every model in cloding can be accessed through one of three authentication modes:

ModeSuffixWhat it doesExample
OpenRouter(none) or -oRoutes through OpenRouter — cheapest multi-model accesscloding -m sonnet
Direct API-aUses your own API key for the providercloding -m sonnet-a
Paid Plan-pLinks to your paid subscription (no API key needed)cloding -m opus-p

Key Features ​

5 CLI tools, 1 command — Switch between Claude Code, Gemini CLI, Codex CLI, Copilot CLI, and OpenCode with a single flag. No context switching.

42x cheaper coding — Qwen 3 Coder at $0.12/Mtok vs Claude Opus at $5/Mtok. Same tools, same workflow, fraction of the cost.

Docker sandboxing — Isolate any tool in a container with access only to the workspace you mount. All 5 CLIs work in Docker mode.

Pipeline mode — Multi-stage coding pipelines with parallel fan-out. Assign different models to Plan, Explore, Code, and Review stages.

Any OpenRouter model — Use any of 300+ models on OpenRouter by ID, or pick from built-in shortcuts with pricing.

How It Works ​

cloding is a thin wrapper that routes API calls through different providers depending on the model you choose. When you run cloding:

  1. Pick a tool + model — Choose from 5 CLI tools and 20+ model shortcuts
  2. Auth is handled — Each model routes through OpenRouter, direct API, or your paid plan
  3. Same CLI experience — You get the exact same tool experience: file editing, terminal access, tool use

That's it. No forks, no patches, no modified binaries. Just configuration.
