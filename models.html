Models & Pricing ​

cloding supports 20+ model shortcuts across 5 CLI tools. Use built-in shortcuts or pass any OpenRouter model ID directly.

OpenRouter Models (via Claude Code) ​

These models route through OpenRouter and use Claude Code as the underlying CLI tool.

Default Model

The default model is Qwen 3 Coder (qwen). Override with -m or the CLODING_DEFAULT_MODEL environment variable.

Using Any OpenRouter Model ​

Not limited to shortcuts — pass any OpenRouter model ID with -m:

bash
cloding -m meta-llama/llama-4-scout
cloding -m google/gemini-2.5-flash
cloding -m anthropic/claude-sonnet-4

Browse the full catalog at openrouter.ai/models.

List All Models ​

bash
cloding --list-models

This shows all configured shortcuts with their full model IDs and pricing.

Choosing the Right Model ​

Different models shine at different tasks:

High-volume coding — Use qwen or deepseek. Dirt-cheap and surprisingly capable for most day-to-day work: writing functions, fixing bugs, adding tests, refactoring.

Architecture and planning — Use opus or sonnet. When you need the model to understand a complex codebase and design a multi-file solution, the extra quality matters.

Code review — Use sonnet, opus, or codex-5. Cost per review is low since reviews are mostly reading.

CI/CD automation — Use qwen. Automated pipelines run many prompts; cost adds up fast. Qwen handles linting fixes, test generation, and boilerplate well.

Large file context — Use gemini or gemini-3. Gemini has a massive context window, ideal for large files.

Using your paid subscription — Use -p variants (opus-p, sonnet-p) for Claude Max, codex-5 for ChatGPT, gemini-3 for Gemini, copilot for GitHub Copilot.

Mix models across tasks

You don't have to pick one model for everything. Use Opus to plan your architecture, then switch to Qwen to implement it.

bash
cloding -m opus-p -p "plan the auth module architecture"
cloding -p "implement the auth module per the plan in PLAN.md"
